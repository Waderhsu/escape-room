# 消失的畢業驚喜 — 密室逃脫

校園主題的網頁密室逃脫遊戲（React + Vite）。

## 本機開發

```bash
npm install
npm run dev
```

## 線上遊玩

部署完成後：[https://waderhsu.github.io/escape-room/](https://waderhsu.github.io/escape-room/)

## 部署

推送到 `main` 分支後，GitHub Actions 會自動建置並發布到 GitHub Pages。

首次使用請在倉庫 **Settings → Pages → Build and deployment** 將 Source 設為 **GitHub Actions**。
